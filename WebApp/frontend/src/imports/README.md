# Ảnh thiết kế tham chiếu

Thư mục giữ ảnh tham chiếu giao diện chat, thi thử, tổng quan quản trị và văn bản/tri thức. `image*.png` là assets đi kèm.

Routes nằm tại [App.tsx](../App.tsx). Các trang tích hợp API ở [pages/](../pages/), chức năng quản lý và state/backend dùng chung ở [pages/server/](../pages/server/), bản sao thiết kế ở [pages/design/](../pages/design/). Nhiều trang có cả khối thật và demo; không xem số liệu mẫu là kết quả backend.

Khi sửa giao diện, theo [rule.md](../../../rule.md) và dùng thành phần hiện có. Lệnh phát triển: [frontend](../../README.md#phát-triển-và-kiểm-thử); chạy sản phẩm: [INSTALL](../../../../docs/INSTALL.md).
