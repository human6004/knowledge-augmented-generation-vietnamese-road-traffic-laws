# Ảnh thiết kế tham chiếu

Thư mục giữ ảnh nhập từ bộ thiết kế UI: chat, thi thử, tổng quan quản trị và quản lý văn bản/tri thức KAG. Các file `image*.png` là assets tham chiếu đi kèm.

Route và trang đang chạy nằm tại [App.tsx](../App.tsx) và [pages/server](../pages/server/). Khi sửa giao diện, theo [rule.md](../../../rule.md) và dùng lại thành phần hiện có.

Lệnh phát triển: [frontend](../../README.md#phát-triển-và-kiểm-thử). Luồng chạy hệ thống: [WebApp](../../../README.MD).
